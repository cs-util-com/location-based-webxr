Tour write probe

Measures how this phone writes into a large file: whether adding a few bytes to the end of a file gets slower as the file grows, and whether the new bytes can be read before saving. It writes test files of up to the size chosen below and deletes or empties them afterwards. Keep the screen on until it says "Done".

1. A file you pick

Choose where to save a new file called write-probe.bin (for example Downloads). If only existing files can be chosen, pick any file you do not need: it will be overwritten.
