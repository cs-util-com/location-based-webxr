About this prototype: tabs plus a context toolbar

Idea. The right panel always has the same three layers: a fixed header (what it is and its name, editable in place), one row of icon actions for exactly this selection, then tabs for the rest. Nothing a station does is ever shown for an item, and the other way round.

  • Adding lives in the station's Content tab: an Add split button (the last used type, plus a menu of every type), and a "+" between story entries to insert one exactly there. The list there mirrors the left tree: stories first, free items below.
  • Separation. Adding is never in the toolbar. The toolbar holds changes; destructive actions sit alone at its far right, in red, after a divider. Station and story deletes ask once, with the count, and can be undone.
  • Radius went to the Place tab, next to the position and the lock: it is a distance on the ground, drawn as a ring on the map while Place is open, so it is set where you look at it. The Details tab only links to it.
  • Card. The name, the description and the station picture are what a visitor reads first, so they sit at the top in the fixed header, foldable with "Card".
