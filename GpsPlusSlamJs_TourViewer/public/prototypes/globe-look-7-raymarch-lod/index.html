Technique. The raymarched cumulus shell of the earlier stable page (bases 1.25 km, tops up to 3.05 km, a weather map of cumulus domes eroded by baked 3D noise, short light march, two-lobe phase, scattering octaves), with ONE quality scale in place of two compiled tiers. Every limit of the march is a uniform: the loops run to fixed bounds and exit early, and a fractional limit weights the last step, so the quality can change every frame without a shader swap or a visible step. The cloud pass draws into a share of one target allocated once at the canvas size (a varying viewport), so its resolution changes without a reallocation. The noise, the weather map and every cell scale stay fixed; only how finely the same field is sampled changes.

What follows the distance, and why that way round.

    What changed from the earlier page.

      Toggles (in the address).

      • ?lod=1 (default): the distance scale; ?lod=0: the two fixed tiers of the earlier page, each its own compiled shader, for a comparison on the same page (the shared changes below apply to both).
      • ?tier=low|high: the device class. At lod 1 it picks the scale's table and caps it; at lod 0 it is the earlier tier.
      • ?dense=0: the earlier, more see-through clouds. ?sea=old: the earlier cheap sea.
      • ?clouds= and ?scale= (lod 0 only): the earlier page's cloud and canvas resolution overrides.
      • ?view=10km|3km|30km, ?sun= as before.

      Measured (laptop integrated GPU through D3D11, a phone's pixel count: 1080x2400 device pixels at the tier's pixel ratio; frozen clock). The machine was shared with other work: repeated runs of the same setting differ by about 9 % (median) and up to 20 %, so a difference below that is not one.
