      How this prototype works

      The character maker saves each character into a library on this device. This page has no line to the maker: it looks into the library again when you close the maker, and when you come back to this tab from the maker in another tab.

      Adding a character copies its pictures into the tour, so the tour keeps it even if it is later deleted from this device.
