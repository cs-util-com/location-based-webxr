Prototype notes: the file explorerfold

Idea. The list is a file tree: stations are top-level rows, story folders come first inside a station, free items below them. Adding happens where you look: the + on a station or story row opens a type menu and the new row appears in place, its name ready to type. Ctrl+K ("Add...") does the same from the keyboard, with type filtering. The right panel is a lean property sheet that shows only what the selected row owns.

  • Radius sits in "Place", next to the position and the lock: it is the arrival zone drawn around the station's dot, so it is about where, not about what (name, text, picture).
  • Adding lives only in the tree (+ on a row) and the palette. The panel's "Add content..." is a shortcut into the same menu, never a second flow.
  • Destroying is always the last thing in the panel, under a separator, in red. Deleting a station or a story asks once with the count and can be undone.
  • Station vs item actions: a station has Earlier/Later and Lock; "Put on the ground", "Align to station" and "Move to station" exist only on items.
