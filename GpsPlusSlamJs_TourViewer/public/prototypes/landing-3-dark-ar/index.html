Where will your tour live?

Your tour is one small file. Keep it somewhere you already use - we only need a link to it.

SETUP

    Paste the share link

    Copy the link from your storage and paste it here. We check it, then turn it into the code your visitors will scan.

    THIS CODE = YOUR TOUR

    Print your codes

    One code per poster. You get a single PDF, ready for any printer.

    cm

    Print at 100 % (actual size), not "fit to page", so the code really comes out 16 cm wide.
    10 POSTERS

    Hang the code where the tour starts

    The code is the tour's anchor. Everything you place later is measured from it, so where and how it hangs matters.

    • 01
      At the start of the tourVisitors scan it first, so put it where your first story is.
    • 02
      Flat, at chest heightAbout 1.2 to 1.5 m. No curled corners, no wrinkles.
    • 03
      Good light, no glareAvoid shiny plastic sleeves and glass that reflects.
    • 04
      Fixed firmlyIf the poster moves, the whole tour moves with it.

    Create the tour in AR

    Now the fun part. Go to the poster with your phone and build the tour right there, in the real place.

    1. 01Stand in front of the poster.
    2. 02Tap Start creating and scan the code.
    3. 03Walk around. Tap to place a text pin or a photo where it belongs.
    4. 04Tap Done. The tour is saved on your phone.

    The camera picture never leaves your phone.

    Your tour is ready

    One last thing: put the new tour file where the old one was, so visitors get it.
