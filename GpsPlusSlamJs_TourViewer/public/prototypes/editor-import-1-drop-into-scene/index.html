Prototype notes

The place decides. Inside a station's circle the file joins that station. Outside every circle it starts a new station on the spot. The label beside the outline says which, before you let go.

  • Dropped files that fail stay where they fell as a marker, with the reason on it. Drop the fixed file on the marker and it takes over the place.
  • Real: pictures are decoded, a .glb gets the tour's structure checks, then three.js parses it and measures it. Real limit: 4096 x 4096 pixels.
  • Made up for this page: the 25 MB and 300,000 triangle limits, the figures of the stone scan, and "Make it lighter", which only pretends to rebuild the file.
