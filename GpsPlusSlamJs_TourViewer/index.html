Tour Viewer

Set up a tour that people open by scanning a printed code: host a zip, print the code, hang it, measure it in AR and place content, then replace the hosted zip. Six steps, one at a time.

Start the tour

This tour runs in augmented reality on your phone. It needs the camera, to show the tour over what you see, and your location, to place it. Nothing is uploaded. Tap the button below; if the browser asks, allow both.

  1. 1 · Host your tour

    Upload a zip to Google Drive, Dropbox, GitHub or OneDrive - a recording from the Recorder app, or the empty starter zip below if you have no recording - then paste its share link here. The printed code will point at this link, so keep the file where it is.

  2. 2 · Print the code

    The code carries the link from step 1. Print it at 100% scale (no fit-to-page), and enter the printed side length so the AR setup can measure it. To try the tour as a visitor on this phone, use the link under the code.

    Open this tour as a visitor
  3. 3 · Hang the code

    Fix the printed code where the tour starts: flat on a wall or a post, at about chest height, in a spot a phone can film squarely from a metre away. It stays there; visitors scan it to open the tour and again in AR to be placed exactly.

4 · Measure the code and place content

Stand at the hung code and start the AR setup. Hold the phone on the code until it is measured, then place text pins and photos where the tour should show them. Finish inside AR when you are done.

AR opens the camera. Keep the printed code in view until the page says it is measured; walking a few metres with GPS reception lets the phone align to the map.

  1. 5 · Download the rebuilt zip

    After Finish in AR, the zip with the measured code and your content is ready here. Download it to this phone; the next step puts it back where the old one is.

  2. 6 · Replace the hosted zip

    Upload the downloaded zip over the one from step 1 so the link, and with it the printed code, stays the same. Google Drive: on drive.google.com in a browser, right-click the file, "Manage versions", "Upload new version" (the Drive phone app cannot do this). Dropbox: upload the file with the same name into the same folder. GitHub: commit it over the same path. OneDrive: upload with the same name and choose "Replace".

Storage

Opened tours are kept on this device (up to five, oldest dropped) so a revisit opens instantly and works offline. A changed file on the host is picked up automatically; clearing is only needed to free space.
