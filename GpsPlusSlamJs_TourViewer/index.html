Tour Viewer

Scan a printed tour code with your phone's camera and the link opens this viewer with that tour. Or paste a link to a hosted tour zip below (Dropbox, GitHub and OneDrive share links work; Google Drive needs an API key or CORS proxy) — entries stream in as needed instead of downloading the whole archive first.

AR works without a tour too; once a tour is open, the camera locates you at its printed codes.

Add the downloaded file to your tour zip under qr/, then re-upload the zip to the same URL — viewers pick the change up automatically.
