File access check

Checks what this browser lets a web page do with a file you choose: save a new file, keep access to it after a reload, rewrite it, and what is left when the tab closes in the middle of a rewrite. Run the steps in order, then take a screenshot of the log.

1. Save a new file

Choose where to save a new file (for example Downloads). It is a small test file.

2. Reload

Reload the page, then go on with step 3.

3. Access after the reload

Asks for access to the kept file again and reads it.

4. Rewrite it, and close the tab during the write

Writes a larger test file over the kept file. While the log counts up, close this tab (swipe it away), then open this page again and run step 5. If the write finishes first, choose a larger size and try again.

5. Read it after reopening

Reports the file's size, a checksum and whether it is whole.

6. Open a file to read and write

Choose the test file from step 1 again, this time through the open dialog. Only a test file is written to.
