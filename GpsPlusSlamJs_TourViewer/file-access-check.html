File access check

Checks what this browser lets a web page do with a file you choose: save a new file, keep access to it after a reload, rewrite it, and what is left when the tab, or the whole browser, closes in the middle of a rewrite. Run the steps in order, then take a screenshot of the log.

1. Save a new file

Choose where to save a new file (for example Downloads). It is a small test file.

2. Reload

Reload the page, then go on with step 3.

3. Access after the reload

Asks for access to the kept file again and reads it.

4. Rewrite it, and close the tab during the write

Writes a larger test file over the kept file. While the log counts up, close this tab (swipe it away), then open this page again and run step 5. If the write finishes first, choose a larger size and try again.

5. Read it after reopening

Reports the file's size, a checksum, whether it is whole, and how the rewrite before it was stopped.

6. Rewrite again, and close the whole browser

The same as step 4, but this time close the whole browser, not only the tab, while the log counts up: open the list of recent apps (swipe up from the bottom of the screen and hold, or tap the square button), then swipe Chrome away. If that does not work, open the phone's Settings, then Apps, then Chrome, and tap Force stop. Then open Chrome and this page again, and run step 5 once more.

7. Open a file to read and write

Choose the test file from step 1 again, this time through the open dialog. Only a test file is written to.

8. Once more as a desktop site

Last, open Chrome's menu (the three dots), tick Desktop site, and reload this page. Nothing else needs to run: the log notes what the browser says about itself in that mode. Then untick Desktop site again, and take the screenshot of the log.
